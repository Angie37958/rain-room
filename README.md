# 听雨 · Rain Room

**给注意力，一处安静的落点。**

选一处雨景，听一会儿雨，做完眼前的一件事。也可以什么都不做，把暂时放不下的话交给雨。

[打开听雨](https://angie37958.github.io/rain-room/) · [安装到手机](#安装到手机)

![听雨桌面预览](./docs/images/desktop.jpg)

## 找一处此刻想待的地方

- **樱花 · 想重新开始**，粉白花枝、溪水与飘落的花瓣。
- **荷塘 · 想放慢一点**，浮叶、水光与近处的落雨。
- **秋林 · 想找回一点温暖**，金黄树影、橙红落叶与暖色水面。
- **冻湖 · 想留点空白**，蓝白冰面、缓慢落雪与柔和风声。
- **晴日 · 想出去透透气**，阳光、白云、野花与太阳雨。
- **窗边 · 想安静待一会儿**，夜雨、暖光与摊开的书。

## 怎么用

1. 选择喜欢的场景，点击右上角「开启声音」，按喜好调节音量。
2. 想专注时，写下眼前的一件事，设定 1–180 分钟，点击「开始专注」。可以随时暂停，完成后手动开始休息。
3. 想放空时，点击「沉浸」留出整片雨景。缓缓移动鼠标，或轻点水面，看看它的回应。
4. 想放下一句话时，在「把杂念，交给雨」中写下，点击「让雨带走」，看它散开、消融。

不想看动画，可以关闭「场景动态」；计时与声音照常使用。手机上觉得画面吃力时，把画面质量调到「省电」。

键盘操作：**空格**开始或暂停计时，**H**进入或退出沉浸。输入文字时不会触发快捷键。

## 关于计时和记录

- 今日统计只计入完整完成的专注轮次，休息、重置和未完成的计时不计入。
- 关闭网页或应用后无法提醒，后台提示音也可能延迟。刷新可以恢复尚未到期的计时，但不会补记关闭期间已经结束的专注。
- 设置、当前任务和记录保存在当前浏览器，不会跨设备同步。更换浏览器或清除站点数据后，原有记录不会跟随。
- 页脚可以「导出记录」或「清除本地数据」。导出内容不包含任务和杂念文字，释放的杂念文字不会保存。

## 安装到手机

**[用手机打开听雨](https://angie37958.github.io/rain-room/)**，按下面的步骤添加到主屏幕，就能从「听雨」图标进入。目前没有单独下载的 APK 或 iPhone 安装包。

### 安卓手机

1. 用 **Chrome** 打开上面的链接。
2. 点击网页底部「安装听雨」，按提示安装；也可以打开浏览器右上角 **⋮ → 添加到主屏幕 → 安装**。
3. 回到手机主屏幕，找到「听雨」图标并打开。不同浏览器的菜单名称可能略有不同。

### iPhone / iPad

1. 用 **Safari** 打开上面的链接。
2. 打开浏览器的**分享**菜单，选择「添加到主屏幕」。
3. 如果看到「作为网页 App 打开」选项，保持开启，再点击「添加」。

如果链接是在微信、QQ 等应用内打开的，请先选择「在浏览器中打开」，再进行安装。

电脑也可以在 Chrome / Edge 中打开听雨，点击网页底部「安装听雨」。不安装也能直接使用。

## 离线与更新

首次联网打开，等页脚显示「已备好离线雨声」，之后就能离线使用。电脑和手机各自保留本地记录。

有新版本时，页脚会出现「更新听雨」。方便时再点击，页面会刷新。
